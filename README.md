# Tamino Locations

A lightweight WordPress plugin for managing travel destinations and locations independently of WooCommerce.

## Features

- Registers a custom post type for locations (`tamino_travel_orte`).
- Provides a dedicated administration menu for location management.
- Supports titles, content, featured images and custom fields.
- Displays thumbnail previews in the WordPress admin list.
- Enables REST API access through WordPress.
- Uses a dedicated location-based URL structure.

## Technical Details

- **Platform:** WordPress
- **Language:** PHP
- **Content Type:** Custom Post Type
- **API:** WordPress REST API

## Installation

1. Copy the `tamino-locations` folder into `wp-content/plugins/`.
2. Activate **Tamino Locations** in the WordPress admin dashboard.
3. Access the location management section through the **Orte** menu.
